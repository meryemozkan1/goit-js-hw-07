# GoIT JavaScript Homework #7 (Module 7)

This project is the seventh JavaScript homework assignment within the GoIT Full Stack Developer program. It focuses on Document Object Model (DOM) traversal, element creation and removal, event handling (`addEventListener`, `removeEventListener`), input interactions, form validations, and dynamic UI rendering.

## 🚀 Live Demo
- [View Live Page](https://meryemozkan1.github.io/goit-js-hw-07/)

## 🛠️ Tasks Included
- **Task 1:** Category counter and element statistics printer using DOM properties.
- **Task 2:** Dynamic image gallery generator based on an array of objects utilizing template literals and `insertAdjacentHTML`.
- **Task 3:** Live name input mutator updating a greeting display dynamically with whitespace trimming.
- **Task 4:** Login form submission handler featuring custom validation alerts, trimmed data extraction, and form resetting.
- **Task 5:** Random background color toggler leveraging a hexadecimal color generator and updating text display.
- **Task 6:** Dynamic box collector builder and destroyer with strict input range validation (1-100) and incremental sizing.

## 🛠️ Technologies & Tools Used
- **JavaScript (ES6+):** DOM API, Event Handling, Higher-order array methods.
- **Prettier:** Code formatting.
- **Git & GitHub:** Version control and GitHub Pages deployment.
